# The GPS Swears It Was a Shortcut

[![make.fun bounty](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9)

Entry for the make.fun bounty **[The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9)** (`u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9`).

## The entry

`main.py` writes the GPS's own one-line excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`
— a single line of plain text, at most 200 characters, no setup, no dialogue tags,
just the excuse itself:

> The map swore that dirt track was a shortcut, and the lake at the end agreed with me until your tires touched it.

## Run it

```sh
python3 main.py
```

Deterministic, no network, no input: every run writes the same line.
